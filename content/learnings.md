# Learnings

Validated findings only — each entry cites the experiment or data that
proved it. Append-only; a reversed learning gets a new dated entry, never
an edit. The planner reads this before every plan; it is the channel's
accumulated judgment.

Format:

```
## YYYY-MM-DD — one-line finding
Evidence: EXP-NNN / insights.md numbers.
Consequence: what the planner now does differently.
```

## 2026-09-12 — Every top post so far is typography; nothing with real footage has proven anything yet
Evidence: first real TikTok Studio data (7-day Content tab, 4 identified
posts). Top 4 by views are 2 slideshows and 2 motion-type videos, 1109 /
242 / 235 / 228 views. Not one uses real footage or a photo of any kind
(sore-wrists carousel is nearly 5x the next best). This is not evidence
that carousels beat video: it is evidence that typography-only content
(in either post slot) is the only thing that has actually shipped enough
to compare, since real footage stayed blocked the whole period.
Consequence: the planner should keep weighting carousels and motion-type
video highest while footage/photo formats stay unproven, and should not
read this as "carousel is the winning format" versus video generally.

## 2026-09-12 — Saves are near zero and the audience skews male on a channel built for women
Evidence: same data pull. Account-wide this week: 23 likes and 1 save
against 2.3K views (roughly 0.4 saves/1000, far under the >15/1000 bar);
viewer gender split 55% male / 42% female; the only search term driving
traffic to a post was the generic "incline push ups". Consequence: view
counts are not yet worth optimising for (per the channel's own measurement
order, they never were). The saves gap and the audience mismatch are the
same problem from two angles: generic, broad-appeal fitness phrasing (hook
text and search-shaped titles) is pulling a general fitness audience
instead of the specific busy-woman audience the brand is written for. The
planner and hook-writing pass should bias toward language and search
phrases that are unmistakably for her, not for a generic fitness search,
even at the cost of some raw reach.
